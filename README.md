# OSPCS Professional Website

A responsive multi-page static website for Optimized Solar Panel Cleaning Services.

## Pages
- Home
- About
- Services
- Projects
- Request a Quote
- Contact

## Run
Open `index.html` locally or upload the entire folder to a GitHub repository and enable GitHub Pages.

## Important before publishing
1. Update the placeholder phone number in the HTML.
2. Update `info@ospcs.co.za` if the business uses a different email.
3. The quote/contact forms currently open the visitor's email app because GitHub Pages is static.
4. For automatic form submissions, replace the form handler in `assets/js/main.js` with Formspree, Netlify Forms, or your own backend.

## Images
The included SVG illustrations are lightweight, original assets designed to work offline and avoid external image licensing/dependency issues. Replace them with real project photographs when available.
